# NVSlim

Download page for NVSlim, a free Windows tool that builds slim NVIDIA and AMD driver installers: pick the parts you want, leave out telemetry and extras, install right away or save a setup file for later.

**Website:** https://outblade.github.io/nvslim/

**Download:** [NVSlim.exe](NVSlim.exe) (Windows 10 and 11, 64-bit, no installer)
